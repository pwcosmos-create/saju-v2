# 🔥 데이터 도착 시 통합 검증 프로토콜 (T+0 Master Protocol)\n\n## 🎯 목적: 코다리 에이전트의 DPSR 안정화 완료 직후, 지연 없이 KPI 분석 및 콘텐츠 제작을 시작하기 위함.\n\n## 📋 전제 조건 (Prerequisites)\n1.  **기술적:** 데이터 파이프라인 안정성률(DPSR) 99.9% 달성 확인.\n2.  **데이터:** 테스트 데이터를 통해 핵심 KPI 측정 지표(DAA, LTV/CAC 등)의 실시간 수신 및 무결성 검증 완료.\n\n## ⚙️ T+0 실행 단계별 액션 플랜 (Action Steps)\n\n### Phase 1: 데이터 Ingestion & 초기 진단 (담당: 코다리 → 현빈)\n*   **액션:** 코다리가 최종 데이터를 추출하여 공유 폴더에 업로드.\n*   **검증 항목 (현빈):**\n    *   데이터 무결성 체크: 예상 범위를 벗어난 아웃라이어 발생 여부? [근거: KPI_Validation_Protocol_v1.md]\n    *   핵심 지표 검증: DAA, LTV/CAC 등 주요 지표의 변화 추이가 과거 가설과 일치하는가?\n    *   **최종 보고:** 현빈은 'KPI Validation Summary Report'를 30분 내에 작성하고 승인.\n\n### Phase 2: 시각화 및 스토리텔링 (담당: Designer → 레오)\n*   **액션:** 데이터 기반으로 Mockup의 실시간 업데이트 테스트 진행.\n*   **검증 항목 (Designer):**\n    *   Mockup 반응성 체크: 지표 변화에 따라 경고/강조 애니메이션이 정상 작동하는가?\n    *   흐름 최적화: 가장 임팩트 있는 데이터 전환 시점(Turning Point)을 명확히 지정.\n*   **결과물:** 최종 `Visual_Motion_Guide` 업데이트 및 레오에게 전달.\n\n### Phase 3: 콘텐츠 제작 가속 (담당: 레오, Writer)\n*   **액션:** 현빈의 검증 결과와 Designer의 시각적 명세서를 결합하여 스크립트 최종 수정 및 영상화 착수.\n*   **주의사항:** 데이터가 불안정했던 과거 사례를 언급하며 '불안감 해소'에 초점을 맞춘 톤앤매너 유지. (Fall-back 스토리라인 활용 가능).\n\n## ⚠️ 비상 상황 대처 (Contingency Plan)\n*   데이터 출처 중 하나(예: VIX 지수)만 불안정할 경우, 해당 데이터를 제외한 **나머지 데이터만으로 Storyline을 구성**하고, '불완전하지만 신뢰 가능한 통제권'이라는 메시지로 대체한다.\n
