# 📊 핵심 KPI 측정 변수 유효성 검증 구조 (DAA, LTV/CAC)
## 🎯 목표: 비즈니스 가설 확정을 위한 데이터 요구사항 정의

**[근거]:** 현빈 개인 메모리 및 CEO 지시사항. 현재 확보된 데이터를 기반으로 '시스템적 통제권' 판매 모델의 경제성을 검증해야 합니다.

### 1. 핵심 KPI 정의
| KPI | 정의 (비즈니스 관점) | 측정 변수 (데이터 요구사항) | 데이터 출처 (예상) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **DAA** (Daily Active Accounts) | 시스템에 접속하여 'SSI 대시보드 미리보기'를 조회한 순 사용자 수. | 1. 유효 계정 ID (Unique User ID)<br>2. 접속 일자/시간 스탬프<br>3. SSI 페이지 접근 여부 (Boolean) | 웹 로그 데이터 (코다리 영역) | **가장 중요한 트래픽 지표.** |
| **LTV** (Life Time Value) | 고객 1명이 우리 시스템을 통해 얻는 총 예상 가치. | 1. 최초 유입 경로/획득 비용(CAC)<br>2. 평균 구독 기간 (Months)<br>3. 월별 평균 결제액 (ARPU) | PayPal 매출 데이터, CRM 데이터 | **PayPal 실매출 데이터가 필수.** |
| **LTV/CAC** | 고객 1명당 순이익률. 비즈니스 모델의 지속 가능성 판단 기준. | LTV / CAC<br>($\text{월 평균 결제액} \times \text{평균 구독 기간}) / \text{획득 비용}$ | PayPal 매출 데이터, 마케팅 지출 로그 (코다리/마케팅 영역) | **최종 의사결정의 핵심 숫자.** |

### 2. 추가 검증 필요 변수
*   **Conversion Funnel Drop-off Rate:** 'SSI 대시보드 미리보기' 조회 $\rightarrow$ '무료 체험 신청' $\rightarrow$ '유료 전환' 단계별 이탈률을 측정해야 합니다. (데이터: 웹 로그)
*   **Churn Rate:** 구독 해지율 및 그 원인 분석이 필요합니다. (데이터: CRM/결제 데이터)

### 3. 다음 스텝 액션 플랜
1.  **[코다리]**: 위 표의 '측정 변수'를 충족하는 형태로 PayPal 매출 데이터를 재구축하고, 웹 로그와 연동할 수 있도록 API 엔드포인트를 안정화하십시오.
2.  **[현빈]**: 데이터가 확보되는 즉시, 이 구조를 기반으로 A/B 테스트 승리 그룹 B의 가설(불안감 $\rightarrow$ 증거 $\rightarrow$ 통제권)이 LTV/CAC에 미치는 영향을 수치적으로 검증하겠습니다.
