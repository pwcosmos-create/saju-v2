# 사주위원회(명리위원회) 지식 카드 제작 요청서

**요청 일자:** 2026-05-23  
**요청 주체:** saju-v2 (홈페이지 AI 심층 풀이 · 인증 카드 조합)  
**반영 경로:** `cards.json` → `status: confirmed`, `council_pass: true` (PASS)  
**현황:** PASS **202장** (격국 10 · 용신 6 · 기신 6 · 심층·[1]~[10] 보유)

---

## 1. 요청 배경

홈페이지 **「AI 심층 풀이 — 사주위원회 인증」** 은 PASS 카드만 조합해 `[1]`~`[10]` 섹션으로 제공합니다.  
카드 수는 늘었으나, 아래 항목이 없거나 제목·본문 형식이 맞지 않으면 **변수 카드 2~3장만** 노출되거나 **용신·직업·월운** 등이 빈약해집니다.

---

## 2. 카드 작성 공통 규격 (필수)

| 항목 | 규격 |
|------|------|
| **제목** | 아래 표의 **정확한 제목 문자열** (Agent Office 등록명과 동일) |
| **summary** | 80~200자, 사용자 화면·무료 풀이용 **한눈 요약** (필수 신설·보강) |
| **body** | `【개요】` `【핵심】` `키워드:` 구조 (변수· 카드) 또는 심층· 해석형 서술 |
| **면책** | 카드 본문에 반복 삽입 **금지** (앱 푸터 1회 처리) |
| **검수** | `council_status: pass`, `status: confirmed` |
| **금지** | 격국 자리에 신살(화개살 등) 혼용, 용신·기신 오행 뒤바뀜 |

---

## 3. 우선 제작·보강 요청 (P0 — 즉시)

### 3-1. 격국 변수 (10격 완비 · 칠살격 명칭)

앱 확정 데이터는 `칠살격`을 쓰고, DB에는 `편관격`만 있는 경우가 있습니다. **둘 다 커버** 요청합니다.

| # | 제목 (정확히) | 비고 |
|---|----------------|------|
| 1 | `변수·격 칠살격` | 편관격(七殺格) 동의어 — **신규** |
| 2 | `변수·격 건록격` | PASS 확인·summary 보강 |
| 3 | `변수·격 월겁격` | PASS 확인·summary 보강 |
| 4~10 | 기존 8격 | 각 카드 **summary** + 【핵심】 사용자 톤 보강 |

### 3-2. 용신·기신·희신 (오행 5종 × 3종)

| # | 제목 패턴 | 수량 |
|---|-----------|------|
| 1 | `변수·운 용신 목` … `수` | 5 (PASS 후 summary) |
| 2 | `변수·운 기신 목` … `수` | 5 (동일) |
| 3 | `변수·운 희신 목` … `수` | 5 (**신규** — 희신 전용) |

### 3-3. 심층·[1]~[10] — summary 필드 일괄 보강

이미 PASS인 10장에 **`summary` 2~4문장** 추가·수정 요청 (본문은 유지 가능).

| 섹션 | 제목 |
|------|------|
| [1] | `심층·[1] 인사·성향` |
| [2] | `심층·[2] 사주팔자` |
| [3] | `심층·[3] 오행 균형` |
| [4] | `심층·[4] 십신·격국` |
| [5] | `심층·[5] 용신·기신` |
| [6] | `심층·[6] 대운·세운` |
| [7] | `심층·[7] 재물` |
| [8] | `심층·[8] 연애·관계` |
| [9] | `심층·[9] 직업` |
| [10] | `심층·[10] 실천·주의` |

## 4. 차순위 제작 요청 (P1 — 2주 내)

### 4-1. 일주 해석 카드 (10천간 × 1장)

제목 예: `갑목 일주 · 성향과 삶의 패턴` (일주 + 천간명 포함, **「샘플」 금지**)

| 천간 | 제목에 포함 문자열 |
|------|-------------------|
| 갑목, 을목, 병화, 정화, 무토, 기토, 경금, 신금, 임수, 계수 | 각 1장 |

기존 `○○ 일주 성향` PASS 카드는 **summary·【핵심】 실생활 예시** 보강.

### 4-2. 지지 관계

| 제목 | 비고 |
|------|------|
| `변수·지지관계 원진` | 신규 |
| `변수·지지관계 반합` | 신규 (필요 시) |
| 기존 삼합·육합·충·형·파·해 | summary 보강 |

### 4-3. 해석· 시리즈 (맞춤 풀이용)

| 제목 | 용도 |
|------|------|
| `해석·신강·신약 생활 패턴` | [4] 오행·신강 보조 |
| `해석·희신·구신 활용` | [5] 보조 |
| `해석·월운 12개월 흐름` | [9] 월별 (확정 월운 데이터와 병행) |
| `해석·궁합·연인 비교` | [7][8] 보조 |

## 5. 선택 제작 (P2)

- `변수·격 비겁격` / `겁재격` (월겁·건록 외 특수 케이스)
- `변수·특수격 종격` / `화격` / `從格` — summary·사례 보강
- 재다신약·관인상생·식상생재 **해석·** 3장 (이미 유사 카드 있으면 통합)
- 남·여·연령대 톤 (`남성 명식·직업 보조` 등) — 중복 최소화

## 6. 제작 시 본문 예시 (변수·격)

```
「변수·격 정재격」
【개요】정재격(正財格)은 월지 본기가 정재(正財)일 때 잡는 격입니다. 안정·가정·꾸준한 수입과 연결됩니다.
【핵심】성실한 관리·현실적 계획에서 강점이 납니다. 일간이 약하면 재성 부담을 줄이고, 강하면 구조화된 수입이 유리합니다.
키워드: 안정, 가정, 성실, 재물 관리
```

**summary 예:**  
`월지 정재 본기의 정재격. 꾸준한 수입·가정·현실 관리에 강하고, 일간 강약에 따라 재성 부담을 조절해야 합니다.`

## 7. 검수·납품 체크리스트 (위원회)

- [ ] 제목이 위 표와 **완전 일치**
- [ ] `summary` 80자 이상
- [ ] 본문에 면책 문단 **없음**
- [ ] PASS 후 `cards.json` mtime 갱신 (saju-v2는 mtime 실시간 반영)
- [ ] 격국 10종·용신/기신/희신 오행 5종 매칭 테스트 가능

---

## 8. saju-v2 측 자동 반영

PASS 등록 즉시:

- `GET /api/gemma24-cards?summary=1` 집계 반영
- 인증 무료 풀이: `searchCouncilDisplayCards` → `[1]`~`[10]` 조합
- 별도 배포 없이 **cards.json 갱신만**으로 반영 (앱 재시작 불필요, mtime 캐시 ~실시간)
